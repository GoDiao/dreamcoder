# 提问与异常状态样稿

日期：2026-10-17。来源：用户对功能覆盖核对的六项批注。

## 本轮范围与优先级

- 展示首次使用与异常提示：未配置服务商、分支失效、工作区有未提交修改、列表加载失败。
- 先展示提问的三种情况：多题、多选、已回答。Computer Use 授权暂未展开。
- 撤销、文件预览和定时任务暂缓，不因此前覆盖核对而自动推进。
- 多终端明确在终端区域内部用 tab 切换，不恢复应用顶部的会话 tab。本轮记录这个设计决定，尚未实施终端画板。

## 提问方案（用户暂时认可）

- 多题放在同一个卡片中，顶部紧凑题目导航，显示填写进度。可以前后切换，全部回答后统一提交。
- 多选使用复选框，提示「可多选」，选项共用轻量背景，不为每个选项增加重边框。
- 两种提问均允许自由填写；与当前应用规则一致，自由回答非空时作为该题最终答案，替代所选选项。
- 未答完整时提交按钮禁用；提交后显示只读答案摘要，不提供会修改历史答案的编辑按钮。
- 已回答样例减少视觉重量，原问题放进折叠详情。默认展示一个完成示例，前两种交互也能实际提交并切换为完成态。

对照源码：`desktop/src/components/chat/AskUserQuestion.tsx` 的多题导航、multiSelect、自由回答、allAnswered 与 submitted 状态。新样稿是外观和交互提议，尚未应用到正式前端。

## 异常提示方案（用户暂时认可）

| 情况 | 放置位置 | 主要操作 |
| --- | --- | --- |
| 未配置模型服务商 | 输入区上方 | 配置服务商，保留输入内容 |
| 分支失效 / 切换失败 | 项目与分支选择区域 | 重新选择分支，保留草稿 |
| 工作区有未提交修改 | 启动位置区域 | 使用独立 worktree，或返回处理；仍需通过实际启动校验 |
| 会话列表加载失败 | 会话列表区域 | 重试；保留已有内容，错误细节折叠 |

异常提示使用局部容器、简短原因和明确操作，不把技术错误堆满页面。样稿中的错误文本是情景示例；正式实现必须使用真实错误码和实际可恢复路径。异常样例按钮仅展示下一步反馈，不打开真实设置、改动仓库或请求服务。

## 用户确认

2026-10-17，用户对本轮状态样稿回复「可以，都先这样」。提问与异常的当前设计暂时认可，作为后续迭代基线；撤销、文件、定时任务仍暂缓，多终端仍采用终端内部 tab。此确认不代表启动正式实现，也不代替浏览器或应用功能验收。
