# 赞助与合作

DreamCoder 由个人利用业余时间维护。欢迎企业和个人赞助，支持项目持续开发。API 服务商、模型平台和开发者工具都可以联系我们。

## 赞助档位

| 档位 | 展示内容 |
| --- | --- |
| **普通赞助** | README「赞助与合作」区展示 logo、一段介绍和链接，官网赞助区同步展示。 |
| **白金赞助** | 包含普通赞助的全部内容，另加：README 顶部横幅；DreamCoder 应用内的 Provider 预设，标注「赞助商」。 |

价格按展示位置和周期单独商议，最短周期为 3 个月。

## 规则

- **赞助不换取产品决策。** 赞助商不能因此要求改动功能、默认设置或路线图。Provider 预设只是让用户更快填好配置，不会成为默认 Provider。
- **我们不接受以下赞助：** 赌博、色情，以及为了搜索排名购买外链的网站。
- **展示内容由维护者审核。** 赞助商提供 logo、介绍和链接，维护者可以要求修改。
- **赞助结束或违反规则时：** 我们会撤下 README 和官网上的展示，并下线 Provider 预设。用户已经保存的 Provider 配置不受影响。
- **维护者保留拒绝或终止任何赞助的权利。**
